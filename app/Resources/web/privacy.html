DS桌宠 隐私政策

更新日期：2026年9月30日　·　生效日期：2026年9月30日　·　适用版本：v1.1 及以后
一句话说明：DS桌宠不申请「网络访问」权限。
本应用没有任何联网能力，无法上传任何数据 —— 这是可以在系统「应用信息 → 权限」里核实的。

一、我们收集哪些信息

不收集任何个人信息。

  • 不申请网络权限，技术上不具备上传能力；
  • 不申请位置、通讯录、短信、相机、麦克风、存储等敏感权限；
  • 不采集设备标识（IMEI / OAID / Android ID 等）；
  • 不集成任何统计、广告、推送类 SDK。

二、申请的权限及用途

为实现桌面宠物这一核心功能，本应用会申请以下权限，全部仅在您的设备本地使用：

权限用来做什么是否上传
悬浮窗
SYSTEM_ALERT_WINDOW		 让桌宠以悬浮窗的形式待在桌面上。这是本应用的核心形态，不申请就无法使用。 否
通知使用权
NotificationListenerService		 读取通知的标题与来源应用名称，让桌宠在头顶冒泡播报。所有内容仅在本机内存中瞬时处理，不保存、不记录、不上传。您可随时在「系统设置 → 通知 → 通知使用权」中关闭。 否
通知
POST_NOTIFICATIONS		 显示「桌宠运行中」的常驻通知，用于保持桌宠存活。 否
软件包可见性
QUERY_ALL_PACKAGES		 把通知的来源应用显示成正确的名称与图标（否则只能显示包名）。不读取应用清单以外的任何内容。 否
前台服务
FOREGROUND_SERVICE		 让桌宠在后台稳定运行，避免被系统回收。 否
加速度传感器
（无需授权）		 用于「摇一摇」甩动桌宠的互动效果。仅在本地实时判断晃动，不采集、不存储、不上传。 否

三、信息的存储

  • 您的设置项（桌宠大小、动作频率、各类开关等）保存在设备本地的应用私有目录中；
  • 卸载本应用后，上述数据随应用一并删除；
  • 本应用不设服务器，因此不存在账号体系，也没有「导出 / 删除个人数据」的流程；
  • 桌宠的动画与语音均为随安装包内置的本地文件，不会下载、不会上传。

四、信息的对外提供

由于不收集任何信息，不存在向任何第三方提供、共享、转让或公开披露信息的情形。

五、第三方 SDK

本应用未集成任何第三方 SDK（不含统计、广告、崩溃上报、推送等服务）。

六、未成年人保护

本应用不收集任何个人信息，未成年人可以正常使用。若监护人对其使用有疑问，可通过下方联系方式与我们联系。

七、权限的关闭方式

  • 悬浮窗：系统设置 → 应用 → DS桌宠 → 显示在其他应用上层
  • 通知使用权：系统设置 → 通知 → 通知使用权 → DS桌宠
  • 所有权限：也可以直接在应用「设置」页点击「收回桌宠」后，于系统设置中关闭

关闭相关权限后，对应功能将不可用，但不会影响其他功能，也不会影响本政策承诺。

八、本政策的变更

如本政策发生变更，我们会在应用内与本页面同步更新，并更新顶部的「更新日期」。重大变更会在应用内以弹窗形式再次向您告知。
